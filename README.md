# Offek Hai - AI Projects

B.Sc. Data Science & Engineering student at the Technion.

## 1. TED Talks RAG Assistant
An AI assistant that answers questions about TED talks, grounded only in the talks' transcripts.
4,005 talks, 14,676 vectors in Pinecone, top-8 retrieval, a guardrail against hallucinations, deployed on Vercel.

**Stack:** Python, FastAPI, Pinecone, OpenAI API
**Code:** https://github.com/offekhai-spec/ted-talks-rag

## 2. Book Buying Agent - Full Stack App
A multi-store book shopping environment: a FastAPI retailer backend (3 stores, 30,000 books, search and buy endpoints), a React chat UI, and a buying flow that re-routes out-of-stock orders to another store.

**Stack:** Python, FastAPI, pandas, React, Vite
**Code:** https://github.com/offekhai-spec/BookBuyingAgent
